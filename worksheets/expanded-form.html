Writing 347 as 300 + 40 + 7 shows what each digit is really worth, and it is the base of mental calculation and column methods. These sheets alternate two tasks: break a number into its place values, and build the number back from a sum. Numbers go from 2 to 4 digits, and every fourth number contains a zero — exactly where children slip, writing 4 + 0 + 5 instead of 400 + 5. The answer key gives every expansion.

🧮 Best for ages 6–10

How to get the most from these sheets

  • Read the number aloud: “three hundred forty-seven” already contains the parts.
  • Use a place-value table (thousands, hundreds, tens, ones) for the first sheets.
  • A zero digit makes no part: 405 = 400 + 5.
  • Check by adding the parts back together.

Frequently asked questions

How many blanks does a number get?

One blank for each digit that is not zero — so 9014 has three blanks: 9000 + 10 + 4.

Which level for which grade?

2 digits in grade 1, 3 digits in grade 2–3, 4 digits in grade 3–4.

Is there an answer key?

Yes, switch it on before printing.
