Coordinates are how maps, games and graphs say exactly where something is. A point is written as a pair (x, y): first how far across, then how far up. Children often swap the two numbers, so these sheets give lots of practice in the right order. The first level uses a small 5×5 grid with big pictures; the second a 10×10 grid with ten pictures; and the third reverses the task, asking children to plot lettered points from their coordinates.

📍 Best for ages 8–12

How to get the most from these sheets

  • Teach the rhyme “along the corridor, then up the stairs”: x first, then y.
  • Put a finger on 0, move along the bottom to x, then straight up to y.
  • Check each answer by reading it back: does (3, 5) really land on the picture?
  • Play sea battle afterwards: it uses the same skill.

Frequently asked questions

Which number comes first?

Always x, the horizontal one, then y, the vertical one: (across, up).

Are there negative numbers?

No, these grids use only the first quadrant (0 to 5 or 0 to 10), as in primary school.

Is there an answer key?

Yes: the coordinates for the reading levels, and the grid with the points plotted for the plotting level.
