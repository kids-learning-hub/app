📲 Schools version of the apps

For pupils of a partner school: these apps accept your school code and open everything, without ads.

You need the school code given by your school, for example KLH-NOUR-2706-XXXXXXXXXX

How to install

  1. Tap “Download” under the app (Android phone or tablet).
  2. Open the downloaded file. If Android asks, allow your browser to “install unknown apps”.
  3. Open the app → Settings → Premium code, then type the school code.
  4. The same code works in all 10 apps.

⚠️ Good to know

  1. If the app is already installed from Google Play, uninstall it first (otherwise Android refuses to install this version).
  2. This version does not update by itself: come back to this page at the start of each term.
  3. Questions? Write to vs.media.ste@gmail.com
